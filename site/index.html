Baixar para Windows

Aplicativo experimental. Requer Python 3.13 com Python Launcher e Tcl/Tk, além de internet para instalar as dependências. O download contém o código e um instalador de dependências.

Comece em três passos

  1. Instale Python 3.13 para Windows, incluindo Python Launcher e Tcl/Tk.
  2. Extraia o ZIP em uma pasta gravável e execute Instalar JS12 Sync.cmd. O script prepara o ambiente e baixa FFmpeg e Deno.
  3. Abra mp4-sync/Abrir JS12 Sync.cmd e configure sua conta Spotify seguindo o manual incluído.

A reprodução acontece no player após a transferência por USB. A instalação de temas no firmware ainda está indisponível. A identificação USB atual exige adaptação para outros aparelhos.
